# v0.1.3 Owner Feedback Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Select all (Ctrl/Cmd+A), a maximized window at start, a clear modal when saving over an open original,
and a cleaner, unclipped selection look; release as 0.1.3.

**Architecture:** Pure logic goes in `workspace.rs` (select all) and in a small pure helper for colours, both
unit-tested. UI wiring stays in `ui.rs`, reusing the existing `confirm_modal`, `modal_open` and `logic`/`ui` split.

**Tech Stack:** Rust 1.95, eframe/egui 0.37 (glow), egui_kittest (dev).

**Spec:** `docs/superpowers/specs/2026-11-12-v0.1.3-feedback-design.md`

## Global Constraints
- An original is never overwritten. That rule is unchanged; only how it is shown changes.
- All new UI text goes through i18n, with key and placeholder parity in `locales/en.txt` and `locales/it.txt`.
  The Italian must be natural.
- Selection must not rely on colour alone: the frame, the badge and the pill all stay.
- Light and dark themes both supported.
- No new runtime dependencies.
- fmt, `clippy --all-targets -D warnings` and tests clean on Linux. Also `cargo clippy --target
  x86_64-apple-darwin --all-targets -- -D warnings` and `--target x86_64-pc-windows-msvc`.

## Review Focus
1. Ctrl+A typed in the Pages field or the password field must select that field's text, not the grid.
   (Task 1: the condition reuses `egui_wants_keyboard_input`, and the manual check covers it.)
2. Ctrl+A with any modal open must do nothing to the grid. (Task 1: it reuses `modal_open`.)
3. "Choose another name", then picking an original again, must show the modal again: no loop, no crash, no
   save. (Task 2, manual check.)
4. Pressing Cancel or Esc in the blocked modal must leave the workspace dirty and unsaved. (Task 2, kittest.)
5. A selected page in the first row or first column must not be clipped, in the light and the dark theme.
   (Task 3, screenshots.)
