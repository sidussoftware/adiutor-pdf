adiutor-pdf for Linux: LGPL-2.1-or-later notice
================================================

The Linux build of adiutor-pdf contains code generated at build time from KDE
Plasma Wayland protocol definitions (XML files), through the Rust crate
wayland-protocols-plasma 0.3.12. The windowing library (winit) uses these
definitions in its Wayland backend. The Windows and macOS builds do not
contain this code.

Source of the protocol definitions
----------------------------------

All protocol XML files bundled in wayland-protocols-plasma 0.3.12 are included
in the plasma-wayland-protocols/ folder next to this notice. They are the
complete source of the LGPL-2.1-or-later material in this program. They are
also available from crates.io (crate wayland-protocols-plasma) and from
https://invent.kde.org/libraries/plasma-wayland-protocols.

Modifying and rebuilding
------------------------

The complete source code of adiutor-pdf for this version, including Cargo.lock
(which pins every dependency), is attached to the same GitHub Release as
"Source code" and is available at https://github.com/sidussoftware/adiutor-pdf.
You may modify the protocol files and rebuild the program with your changes:
follow "Build from source" in README.md, and point Cargo at your modified copy
of wayland-protocols-plasma (for example with a [patch.crates-io] entry in
Cargo.toml).
